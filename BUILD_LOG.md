# BUILD_LOG.md — FrostMind Engineering Log & Evidence

## Entry 1: Problem Definition & Scope
- Theme: Deep Tech & Industry: T-5. Open Source & Innovation
- Problem Statement v2: Urban working families and multi-generational households struggle with high perishable food wastage (losing ₹1,000–₹2,500 monthly) because unorganized storage hides items past expiry, while elderly members miss meal-dependent prescriptions.
- Solution Direction: A ₹4,000 open-source offline edge kit using passive receipt logging and ambient meal-time voice/display alerts.

## Entry 3: Stranger Test & UX Iterations
- Stranger Test Result: Users hesitated navigating between separate tabs for inputting inventory versus checking door-open alerts.
- UX Changes Implemented: Combined layout into a single vertical scrolling page and added a "⚡ Load Sample Receipt" button for instant testing.
